# 生き物図かん Gemini学習サポートサイト

**公開URL：** https://a-tozak.github.io/ikimono-zukan-gemini/

小学校4年生の国語単元「わたしのクラスの『生き物図かん』」（東京書籍 新編 新しい国語4年）で使う、子ども向けGemini活用サポートサイト。

---

## プロジェクトの目的

- 子どもが自分で生き物を選び・調べ・構成を考え・リーフレットを仕上げるまでを、Gemini との対話でサポートする
- プロンプトをコピーして Gemini に貼り付けるだけで使える、シンプルな1ページサイト
- 端末はChromebook（Google アカウントでGeminiにアクセス）

---

## サイトの構成・機能

### ナビゲーション（sticky）

| 要素 | 内容 |
|---|---|
| タイトル | 生き物図かん |
| 生き物名入力 | `<input id="cname">` — 入力すると全プロンプトの `{{いきもの}}` が即時置換される |
| Geminiで開くボタン | `https://gemini.google.com/` を新規タブで開く |
| 今日の振り返りボタン | Google Forms（全9時間共通）を新規タブで開く |
| フェーズリンク | ①〜④ のセクションへのアンカーリンク（スクロールスパイつき）|

### 振り返りフォームURL（変更しないこと）
```
https://docs.google.com/forms/d/e/1FAIpQLSdj32DfB5hld4JUuGmfbClQm3pQgnrJX-ScoAU-9nU9w606xg/viewform?usp=header
```

### プロンプトカードの構造

各カードは以下の要素で構成：

1. **価値提案バー** — 😓「こんな悩みに」/ ✅「こうなる」の2列
2. **カードヘッダー** — ラベル・タイトル・説明文
3. **プロンプト本文** — `<textarea readonly id="p-xxxx">` に `{{いきもの}}` プレースホルダー
4. **アクション行** — 「コピーする」ボタン ＋「Gemini で開く」リンク
5. **ヒント** — 色分けされたボーダー付きボックス

### プロンプトID一覧

| ID | フェーズ | 内容 |
|---|---|---|
| `p-select` | ① 生き物を選ぶ | 対話型の生き物えらびプロンプト |
| `p-search` | ② 調べる・確かめる | 調べるポイントと検索キーワードの提案 |
| `p-factcheck` | ② 調べる・確かめる | 調べた内容のファクトチェック |
| `p-comp` | ③ 構成メモを作る | 段落整理の対話型プロンプト |
| `p-theme` | ③ 構成メモを作る | 「一番伝えたいこと」を決めるプロンプト |
| `p-polish` | ④ もっとよくする | リーフレット評価・改善提案 |
| `p-write` | ④ もっとよくする | はじめ・なか・おわりの書き方ヒント |

### JavaScript の主な処理

```javascript
// 生き物名の即時反映
input.addEventListener('input', updateAll);
// → originals[id] に保存したテンプレートの {{いきもの}} を置換し textarea に反映

// コピーボタン
copyPrompt(id, btn)
// → navigator.clipboard.writeText() → 失敗時は execCommand('copy') でフォールバック
// → ボタンを2秒間「コピーしました ✓」に変化 + トースト表示

// スクロールスパイ
// → IntersectionObserver でセクションを監視 → .active クラスを付け外し
```
